# 玄鉴仙族 · 几笔长生

基于《玄鉴仙族》设定制作的非官方同人 **类幸存者游戏**。在青白山场中走位避险、自动清怪、收取经验，逐步构筑神通与果位，迎战最后的执阵首领。

**当前版本：0.22.0 · 主修与收割** · 本地 H5 · 支持离线游玩

## 开始游玩

### 离线发行包

下载 [0.22.0 离线包](发行版/玄鉴仙族·几笔长生-0.22.0.zip)，解压后双击 `开始游戏.html`。运行库与首页图片已打包，无需联网或安装开发依赖；同目录的 `guide.html` 提供详细规则。

### 从源码启动

macOS 可双击根目录的 `启动游戏.command`，脚本使用 **Python 3** 启动本地服务并打开浏览器。关闭该终端窗口即可停止服务。

也可以在项目根目录运行：

```sh
python3 -m http.server 18743 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:18743/>。游戏使用本地运行库，不需要先执行 `npm install`；Node.js 仅在运行开发测试时需要。

## 核心玩法

**走位聚怪与避险 → 自动清怪 → 靠近收取经验 → 升级补短板 → 挑战更强敌群与机缘。**

- **五件器物**：青尺剑、青乌弓、杜若枪、六雷玄罚令、重明洞玄屏，分别提供近战、远射、贯穿等不同基础。重明洞玄屏没有伤害普攻，需要依靠神通杀敌，适合熟悉规则后尝试。
- **十九道神通与八类修行强化**：普通升级在候选充足时提供两道神通和一项强化。新学、升重、补生存或改善回收，各自占用一次成长机会。
- **主修与法力取舍**：普通攻击不耗法力，自动神通和器物技共用法力。首道承担伤害的自动神通默认成为主修，可在参悟或暂停界面更换，也可选均衡调度。主修与紧急防御优先蓄法，其他缺法神通先短暂让行，再轮候施放。
- **两条果位路线**：明阳与渌水均需五道指定神通各至少一重，并有其中一道达到三重。修行强化不计入同参；已开始的路线有缺项／精修候选保底，但提供机会不等于自动补齐。
- **六种箓气与可选机缘**：每局受箓择一；宝藏、守点、追猎和试阵让玩家决定是否离开安全路线争取成长。

S／A／B 是本作强度评级，一至三重是局内修习等级。高评级不代表最适合当前搭配；未成果位时也需要依靠器物与神通组合生存。

### 一局如何结束

标准挑战在 **11 分 15 秒开启终阵**，击败终阵首领才算获胜。“约十二分钟”是体验目标，不是到点自动结算；普通首领被击败后战斗仍会继续。

胜利后可保留本局修为继续无尽，也可重开尝试其他搭配。喘息阶段适合回收经验，但残敌、精英和首领仍会行动。

## 操作

以移动和自动攻击为基础，其他能力按需使用。

| 操作 | 按键／方式 |
| --- | --- |
| 移动 | WASD、方向键，或点击地面 |
| 通用瞬移 | **空格**／战场按钮；沿移动方向位移，冷却 6 秒，不耗法力、不额外提供无敌 |
| 升级选择 | 点击卡片，或 1／2／3；受箓时可用 1—6 |
| 暂停／继续 | P／Esc |
| 神通谱 | Tab；查阅时暂停 |
| 开关音效 | M |
| 器物技 | 默认自动；G 手动使用，R 切换自动／手动 |
| 蓄能果位／指定神通 | F；明阳成型后释放六合敕令，成型前可在暂停界面指定手动神通 |
| 血漠挪移 | E；需赤断镞、身在自己的血漠内，并满足法力与冷却条件 |
| 竭命功成 | Q；需对应箓气，每次消耗不可恢复的寿元 |

明阳果位以蓄能六合敕令制造禁闭与消弹窗口，不额外召出仙将；渌水果位强化持续雨势和破护延续。原有明阳甲兵联动仍保留。详细数值与限制见 [游戏指南](guide.html)。

## 结算与记录

结算会回顾搭配、受伤来源、主修、机缘、果位成型时刻与缺法等待，并区分“有进度候选但选择了强化”和“选择时仍没有进度候选”，方便决定下一局的尝试。

修行录保存在当前浏览器本地，可导出备份、合并导入；不保存战斗中途进度。不同浏览器或打开地址的记录未必共用，换入口前建议先导出。源码游玩时可固定使用上述本地地址。

## 开发与验证

在根目录使用 Node.js 运行相关检查：

```sh
node tests/core-loop.cjs
node tests/playability.cjs
node tests/training.cjs
node tests/fruit.cjs
node tests/fruit-active.cjs
node tests/rarity.cjs
node tests/dash.cjs
node tests/readability.cjs
```

完整输入驱动对照入口：

```sh
node tests/core-flow.cjs
```

该脚本按固定策略移动、选卡与使用瞬移，保留自然成长和死亡。它不是浏览器交互测试，也不能代替真人试玩。

0.22 随版保存了 98 项相关回归和其他检查结果，见 [验证记录](tests/core-0.22-results.json)；变化与已知限制见 [0.22 版本说明](docs/0.22.0-主修与收割.md)。当前仍需真人完整流程验证成长反馈、战场可读性与不同箓气的平衡，不能将构造场景或模拟通关当作体验验收完成。
